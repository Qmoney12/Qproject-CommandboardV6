# Productivity Whiteboard App

## Overview
An interactive whiteboard app where you organize tasks as cards, connect them, add branches, and attach side notes. Built with the help of AI-generated starter code and refined manually.

## Features
- Drag-and-drop cards on a canvas
- Connect cards to build branches/flows
- Add side notes to cards
- Dark theme with gray accents

## Tech Stack
- React + TypeScript
- Tailwind CSS
- Zustand (for state)
- DnD kit (drag-and-drop interactions)

## Getting Started
1. `npm install`
2. `npm run dev`
3. Visit `http://localhost:5173`
